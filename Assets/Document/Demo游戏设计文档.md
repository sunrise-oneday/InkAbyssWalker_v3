```
探索地图 → 遇敌 → 姿态回合制战斗 → 获得奖励 → 继续探索 → Boss战
```

## 二、世界观与美术风格

### 2.1 世界观概述

玩家扮演一名"墨渊行者"，深入名为"墨渊"的异世界。墨渊是一个由水墨构成的多层深渊，每一层都有独特的生态和危险。行者利用水墨之力战斗，通过切换不同的"战斗姿态"来应对各种敌人。

### 2.2 美术风格

- **整体风格**：2D 水墨横版，参考《大神》《墨术》
- **色调**：以黑、白、灰为主，辅以淡墨蓝和朱砂红作为点缀
- **笔触**：所有视觉元素带有毛笔笔触边缘，模拟宣纸晕染效果
- **动态**：角色和特效带有水墨飞溅、墨滴扩散的粒子效果
- **参考关键词**：Chinese ink wash painting, sumi-e, brush stroke, ink splatter, xuan paper texture

## 四、核心玩法循环

### 4.1 探索阶段

```
移动（WASD）→ 跳跃（Space）→ 攻击障碍（鼠标左键）→ 画技移动（Q/E/R）→ 遇敌 → 进入战斗
```

**探索动作**：
- 左右移动 + 跳跃（2D 平台）
- 轻攻击：破坏墨块障碍物
- 画技1（Q）：墨丝摆荡 — 发射钩索摆荡到高处
- 画技2（E）：泼墨跳 — 二段跳
- 画技3（R）：墨翼滑翔 — 空中滑翔
- 闪避（Shift）：快速位移，可穿过敌人
- 互动（F）：开启宝箱、进入商店、触发事件

### 4.2 战斗阶段

```
回合开始 → 结算持续效果 → 回复资源 → 玩家行动 → 敌人行动 → 回合结束
```

**玩家每回合可执行**：
- 使用技能（消耗墨力 + 1行动点）
- 切换姿态（免费，限1次/回合）
- 格挡（进入格挡姿态，不消耗行动点）
- 闪避（进入闪避姿态，不消耗行动点）
- 使用消耗品（消耗1行动点）
- 结束回合

### 5.2 姿态切换规则

- 每回合可切换姿态 **1 次**，不消耗行动点
- 切换在玩家行动阶段开始时进行
- 切换后立即获得新姿态的属性加成
- 初始姿态为 **初临**

### 5.3 格挡与闪避系统

#### 普通格挡
- 进入格挡姿态后，受到的伤害减少 50%
- 连续格挡加成：第2次 60%，第3次 70%

#### 完美格挡（弹反）
- 时机窗口：敌人攻击判定前 **0.15 秒**
- 效果：完全免疫伤害 + 自动反击（80% 攻击力伤害）+ 回复 1 点墨力
- 视觉反馈：金色墨滴扩散 + 时间暂停 0.2 秒

#### 普通闪避
- 基础闪避率：50%（流墨姿态下 90%）
- 闪避成功：完全免疫伤害
- 连续闪避加成：第2次后下回合攻击+20%

#### 完美闪避
- 时机窗口：敌人攻击判定前 **0.2 秒**
- 效果：完全免疫伤害 + 时间减缓 1 秒 + 下回合攻击+30%
- 视觉反馈：水墨残影 + 慢动作

### 5.4 资源系统

| 资源 | 初始值 | 恢复方式 |
|------|--------|----------|

## 八、地图设计

### 8.1 第1层：墨渊·表层

**主题**：水墨深渊的最表层，光线尚可，墨色较浅。

**色调**：
- 背景：淡墨灰渐变（上深下浅）
- 地面：深灰墨色石板
- 装饰：枯墨树枝、散落的墨滴、半透明的墨雾

**房间布局**（4个房间，线性+分支）：

```
[起点房间] → [战斗房间A] → [商店房间]
                  ↓
              [战斗房间B] → [Boss房间]
```

#### 房间1：起点房间（安全区）
- 大小：16×10 格（每格 32×32 像素）
- 内容：无敌人，1个宝箱（获得第一个符文"坚韧"）
- 教学：显示移动/跳跃/攻击的基础操作提示

#### 房间2：战斗房间A
- 大小：20×10 格
- 敌人：2只墨渍怪
- 地形：中间有1个平台（跳跃可达）
- 奖励：15 墨币

#### 房间3：商店房间
- 大小：12×10 格
- NPC：墨商（固定位置）
- 商品：3个符文 + 2种消耗品

#### 房间4：战斗房间B
- 大小：24×10 格
- 敌人：1只墨丝傀儡 + 1只墨甲虫
- 地形：2个平台 + 1个需要画技到达的高台
- 奖励：20 墨币 + 1个宝箱

#### 房间5：Boss房间
- 大小：20×10 格
- Boss：墨渊守卫·玄甲
- 地形：平坦，无平台
- 奖励：100 墨币 + 1魂玉 + Demo通关

## 十、Demo 通关条件与流程

### 10.1 通关条件
