# 背包面板 UI 生图提示词文档（水墨画风格）

## 整体风格

```
Traditional Chinese ink wash painting (shui-mo hua) game UI, semi-transparent panels with ink brush stroke borders, calligraphic text elements, warm sepia parchment tones, gold and cyan accent colors in ink wash style, 16:9 aspect ratio
```

## 反向提示词
```
modern flat design, neon colors, pixel art, 3D render, cartoon, anime, photorealistic, bright saturated colors, plastic texture
```

---

## 面板整体布局

```
Traditional Chinese ink wash painting game inventory panel UI, two-column layout:
Left side: scrollable item grid with 5 columns, each slot has soft ink wash background with colored ink border indicating rarity
Right side top: character stats panel with calligraphic icon+text rows for each attribute, ink brush stroke dividers
Right side middle: skill rune equipment slots grouped by form, connected by ink brush stroke lines
Right side bottom: item detail panel with name, description, rarity badge in ink wash style
Top bar: panel title in calligraphic style with shop button and close button
Background: warm sepia parchment texture, accent colors: gold ink for legendary, purple ink for epic, blue ink for rare, gray ink for common
```

## 属性面板行设计

```
Game stat row UI element, traditional Chinese ink wash painting style:
Left: small icon rendered in ink brush strokes (sword for attack, heart for HP, shield for defense, droplet for MP)
Center: attribute name in calligraphic ink text
Right: base value in ink text + bonus value in green ink with + prefix
Example: "⚔ 攻击: 15 (+8)" in calligraphic style
Subtle horizontal ink brush stroke divider between rows
Warm sepia parchment background
```
