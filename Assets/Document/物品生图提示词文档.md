# 物品生图提示词文档（水墨画风格）

## 通用风格前缀

所有物品图标统一风格：
```
Traditional Chinese ink wash painting (shui-mo hua) game item icon, brush stroke texture, sepia parchment paper background, centered composition, elegant calligraphic style, soft ink gradients, muted earth tones, 256x256, no text, no border
```

## 反向提示词
```
modern style, neon colors, pixel art, 3D render, cartoon, anime, photorealistic, bright saturated colors, plastic texture, glossy finish
```
