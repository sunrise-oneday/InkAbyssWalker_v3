# 墨渊行者 · 美术生图说明文档

> 本文档为 AI 生图工具（Stable Diffusion / Midjourney / DALL-E 等）提供统一的提示词和美术规格说明。
> 所有美术资源需遵循 **水墨风格**（Chinese Ink Wash / Sumi-e），以黑、白、灰为主，辅以淡墨蓝和朱砂红。

## 一、通用美术规范

### 1.1 风格基准

| 项目 | 规范 |
|------|------|
| 整体风格 | 2D 水墨横版，参考《大神》《墨术》 |
| 主色调 | 黑、白、灰，辅以淡墨蓝 (#4A6B8A) 和朱砂红 (#C23B22) |
| 笔触 | 所有视觉元素带有毛笔笔触边缘，模拟宣纸晕染效果 |
| 背景质感 | 宣纸纹理底纹（xuan paper texture） |
| 通用负面提示词 | `no 3D, no realistic photo, no anime cel-shading, no western cartoon, no neon colors, no gradient mesh` |

### 1.2 通用提示词前缀

```
Chinese ink wash painting style, sumi-e aesthetic, brush stroke edges, 
xuan paper texture background, traditional Chinese art, monochrome with 
occasional vermillion red and ink blue accents, minimalist composition
```

## 四、三形态设计与技能重设计

### 4.1 形态设计理念

游戏目前有 **3 个形态**（初临、流墨、守墨），设计文档规划了 5 个。以下基于现有 3 个形态重新设计技能，确保各形态间有配合协同：

**形态配合设计核心**：
- **初临**（均衡）：施加元素状态（火/冰），为其他形态创造条件
- **流墨**（闪避/连击）：对已有元素状态的敌人打出追击伤害
- **守墨**（防御/控制）：提供护盾和控制，为切换形态争取回合

### 4.2 初临形态（ChuLin · 均衡型）

**定位**：起始形态，负责施加元素状态、平衡攻防。

|--------|-----|------|------|------|------|----------|
| **墨刺** | 2 | 8 | 2 | 无 | 基础刺击，削韧 | 起手攒充能 |
| **炎墨** | 4 | 12 | 1 | Fire | 施加火元素附着 2 回合 | 为流墨"焰追"创造条件 |
| **寒墨** | 4 | 12 | 1 | Ice | 施加冰元素附着 2 回合 | 为流墨"冰追"创造条件 |

## 十、生成注意事项

### 10.1 文件命名规范

- 统一使用英文命名，驼峰式：`Icon_ArmorBreak.png`
- Buff 图标前缀：`Icon_`
- 意图图标前缀：`Intent_`
- 技能图标前缀：`Skill_`
- 形态图标前缀：`Form_`
- UI 元素前缀：`UI_`

### 10.2 导出设置

| 项目 | 值 |
|------|-----|
| 格式 | PNG-24 |
| 透明度 | 支持 Alpha 通道 |
| 色彩空间 | sRGB |
| 图标尺寸 | 64x64 或 128x128（见各章节标注） |
| 背景图尺寸 | 1920x1080 |

### 10.3 Unity 导入设置

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Filter Mode: Point（像素风格）或 Bilinear（水墨晕染）
- Compression: 攻略用 None / 发布用 Default
- 确保 Generate Mip Maps 关闭（UI 元素）
