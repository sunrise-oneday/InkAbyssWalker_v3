# 探索系统

## PlayerController (`Assets/Scripts/Core/PlayerController.cs`)
探索玩家控制器，MonoBehaviour，继承 EntityBase。
- 拥有探索状态机 `StateMachine<PlayerController>`（7 个状态）
- 输入事件绑定：GameplayInputReader 事件 → 状态内逻辑响应
- 移动/跳跃/冲刺/连击核心逻辑
- 平台物理锁：与 MovingPlatform2D 速度同步
- 技能解锁系统：PlayerPrefs 持久化，连招锁定（如 JumpInputBuffered 检查解锁状态后响应）

## 探索能力解锁

### ExplorationAbility 枚举
Jump / Dash / Attack / DoubleJump / RangedAttack / WallJump / Ult_Sword / Ult_Ice

### AbilityUnlockTrigger
能力解锁触发器，碰撞进入时写入 PlayerPrefs（key：`Ability_<name>`），然后销毁自身

## 平台 (`Assets/Scripts/MovingPlatform2D.cs`)
2D 移动平台，PlayerController 在其上时实现速度同步防止漂移

## 冲刺水晶 (`Assets/Scripts/Item/DashGem.cs`)
Celeste 风格的冲刺重置水晶：碰撞后重置冲刺可用性 + 冷却计时，3 秒后重生

## 存档系统

### SaveManager (`Assets/Scripts/Core/SaveManager.cs`)
纯 C# 单例。检查点坐标持久化（PlayerPrefs）。
坐标防火墙：拦截战斗场景中的脏坐标（>1500），防止战斗场景坐标污染探索存档。

### CheckpointTrigger (`Assets/Scripts/Save/CheckpointTrigger.cs`)
检查点触发器：保存坐标到 PlayerPrefs + 恢复满 HP/MP

## CameraController2D (`Assets/Scripts/Core/CameraController2D.cs`)
2D 摄像机跟踪。SmoothDamp 平滑跟随 PlayerController.transform。大地图边界限制。
