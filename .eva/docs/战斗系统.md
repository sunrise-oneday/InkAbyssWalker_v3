# 战斗系统

## 核心调度

### BattleManager (`Assets/Scripts/Core/BattleManager.cs`)
战斗总控制器，单例（MonoBehaviour）。协调开战/收战全流程：
- `StartBattle(playerController, enemy)` → 异步场景加载 → 实体生成 → 装备效果绑定 → 先制判定
- `EndBattle()` → 资源回退 → 场景卸载 → 存档
- 通过 BattleStatSyncBridge 在开战/收战时 Apply/Restore 装备属性到 CharacterStats

### BattleTurnManager (`Assets/Scripts/Core/BattleTurnManager.cs`)
回合管理器，定义 `BattlePhase` 枚举：`None → Setup → PlayerTurn → EnemyTurn → Win → Lose`
- `EnterPlayerTurn()` → 补充 AP/MP → 激活 ActionPanel
- `EnterEnemyTurn()` → 怪物依次行动 → 格挡/闪避判定
- 目标选择系统

### BattleCombatResolver (`Assets/Scripts/Core/BattleCombatResolver.cs`)
攻防判定解析器，单例：
- 完美格挡（0.12s 窗口）/ 普通格挡（0.30s 窗口）/ 闪避判定
- 伤害结算
- `CheckBattleOver()` 胜负裁定

### BattleEffectManager (`Assets/Scripts/Core/BattleEffectManager.cs`)
视觉特效管理器：魔女时间（子弹时间）、镜头抖动、HitStop

### BattleResourceManager (`Assets/Scripts/Core/BattleResourceManager.cs`)
共享资源管理器：AP/MP/大招能量条

## 战斗实体

### PlayerBattleEntity (`Assets/Scripts/Battle/Base/PlayerBattleEntity.cs`)
玩家战斗实体，拥有独立的战斗状态机 `battleStateMachine`（不与探索状态机共享）。
- AP 管理系统
- 形态切换（PlayerForm），每种形态有独立的技能列表
- 技能（Skill）和大招（UltimateSkill）释放
- 格挡/闪避输入响应

### EnemyBattleEntity (`Assets/Scripts/Battle/Base/EnemyBattleEntity.cs`)
敌人战斗实体，动画事件驱动多段连击。
- 通过观察者模式监听 `OnBuffsChanged` / `OnBreakChanged` 自动切换状态
- EnemyAttackSequence 配置连击序列

### CharacterStats (`Assets/Scripts/Battle/Base/CharacterStats.cs`)
属性组件，HP/MP/Break（破防值）/ Buff 容器。
- `TakeDamage()` → Buff 拦截器链 → 破防倍率计算 → 触发 OnHPChanged/OnBreakChanged 事件
- `AddBuff()` → 自动检测元素反应 → 同名 Buff 叠层刷新
- `TickBuffs()` → 回合开始时 Buff 递减与移除

## Buff 系统 (`Assets/Scripts/Battle/Buff/`)

策略模式 + 责任链模式。Buff 抽象基类生命周期钩子：
- `OnApply()` / `OnTurnStart()` / `OnTurnEnd()` / `OnRemove()`
- `OnBeforeTakeDamage(ref damage)` → 伤害计算前拦截修改（责任链）

已实现 Buff：`FireAuraBuff`（灼烧）、`IceAuraBuff`（减速）、`StunBuff`（眩晕）、`VulnerabilityBuff`（易伤）

## 元素反应系统

在 `CharacterStats.AddBuff()` 中自动检测：
- **融化**（Fire + Ice）→ 额外伤害 + 削韧 + 易伤
- **蒸发**（Water + Fire）→ 无视防御伤害

## 战斗 UI (`Assets/Scripts/Battle/UI/`)

### BattleUIController
Facade 模式，统一管理所有战斗面板（info/action/result/tooltip/HUD）

### EntityHUD
实体血条/Buff 图标，全事件驱动（监听 CharacterStats.OnHPChanged 等）

### FixedTooltipPanel
固定位置技能详情提示，渐入渐出/弹性缩放/文字交叉淡入淡出
