# 商店与背包子系统

命名空间：`StoreAndInventory`
路径：`Assets/Script/StoreAndInventory/`

独立完整的 MVC 分层子系统，包含数据定义、服务层、UI 层和主工程集成桥。

## 数据层 (`Data/`)

### 物品类型层次
- `ItemBase` (ScriptableObject)：id/name/description/icon/rarity/price/stack，Editor 中自动命名
- `Equipment`：装备，含 StatModifier 列表 + SkillModifier 列表 + GameplayEffectSO 列表
- `Consumable`：消耗品，含 useEffects + consumeOnUse + useContext
- `StoryItem`：剧情物品
- `ItemEnums`：ItemCategory / ItemRarity / UseContext / StatType / SkillModTarget / SkillModType

### 运行时数据
- `ItemStack`：definitionId + count + instanceGuid
- `InventoryData`：slots (List\<ItemStack\>)
- `EquipmentData`：RuneSlotEntry 列表
- `CurrencyWallet`：CurrencyEntry 列表（Ink 墨币 / Spirit 灵石预留）
- `ShopEntry`：item + priceOverride + stock
- `ShopTableSO` (ScriptableObject)：商店配置表

### 效果数据
- `StatModifier`：stat + flat（固定值）+ percent（百分比）
- `SkillModifier`：targetKind + targetId + modType + value
- `GameplayEffectSO` (ScriptableObject)：lifestealPercent 等

## 服务层 (`Services/`)

严格分层：UI 不能直接操作数据层，必须通过 Service API。事件驱动自动刷新。

### Inventory
背包运行时：增删查改、堆叠管理、`TryConsumeAt()` 消耗品使用

### EquipmentService
装备/符文系统：装/卸/取/属性聚合查询、存档导出导入

### WalletService
钱包服务：Get/Has/Add/TrySpend，防溢出保护

### ShopService
商店服务：Open/Close/TryBuy/TrySell/限购归档/价格计算。购买失败自动回滚货币。

### StoreSaveService
存档服务：`CaptureAll()` / `ApplyAll()`，JSON 序列化 SaveBundle（包含所有子系统数据）

## 集成桥 (`Integration/`)

### BattleStatSyncBridge
战斗属性同步桥：开战 Apply（装备加成写入 CharacterStats）→ 收战 Restore

### EquipmentBattleStatApplicator
装备战斗属性应用器：快照 + 还原、Effective 五维计算（Base + Flat + Percent）

### StoreInventoryInputBridge
商店/背包输入桥：I 键开背包 / F 键开商店，暂停/恢复探索输入

### ShopZoneTrigger
商店区域触发器，碰撞进入时打开商店

## UI 层 (`UI/`)

- `StoreInventoryPanelController`：面板总控制器，Shop/Inventory 互斥开关
- `InventoryUI`：背包面板（物品列表/属性行/符文槽/信息面板/使用/装备）
- `ShopUI`：商店面板（Buy/Sell 标签页/货币显示/购买判定）
- `EquipmentSlotUI` / `InventoryItemUI` / `ShopItemUI` / `SellItemUI`：各 UI 项
- `ItemTooltipUI`：物品悬浮提示

## 编辑器扩展 (`Editor/`)

- `ReadOnlyAttribute` + `ReadOnlyDrawer`：Inspector 只读显示 PropertyDrawer
