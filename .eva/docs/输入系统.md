# 输入系统

路径：`Assets/Scripts/Input/`

基于 Unity InputSystem 的事件驱动输入架构。

## InputManager (`Assets/Scripts/Input/InputManager.cs`)
单例（MonoBehaviour），持有 `InputAssets` 实例。
- 支持按键绑定覆盖的保存/加载
- 在 Awake 时创建并启用 InputAssets

## InputAssets
Unity InputSystem 自动生成的 C# 包装类，定义 3 个 Action Map：

### GamePlayer Action Map
- Move（WASD/摇杆）、Look（鼠标）、Fire（鼠标左键）
- Jump（空格）、Dash（Shift）
- OpenInventory（I）、OpenShop（F）

### Battle Action Map
- Parry（E）、Dodge（Shift）、Aim（Q）、Shoot（鼠标左键）
- QuickForm1（1）、QuickForm2（2）

### UI Action Map
- Navigate、Submit、Cancel、Point、Click、ScrollWheel

## 输入读取器

### GameplayInputReader (`Assets/Scripts/Input/GameplayInputReader.cs`)
探索输入读取器，实现 `InputAssets.IGamePlayerActions` 接口。
通过 C# event Action 委托广播输入：
- `OnMoveInput(Vector2)` / `OnLookInput(Vector2)` / `OnFirePressed` / `OnFireReleased`
- `OnJumpPressed` / `OnDashPressed`
- OnOpenInventory / OnOpenShop 为空实现（由 StoreInventoryInputBridge 接管）

### BattleInputReader (`Assets/Scripts/Input/BattleInputReader.cs`)
战斗输入读取器，通过事件广播：Parry/Dodge/Aim/Shoot/QuickForm

### UIInputReader (`Assets/Scripts/Input/UIInputReader.cs`)
UI 输入读取器，通过事件广播：Navigate/Submit/Cancel/Point/Click/Scroll

## 按键重绑定
- `RebindActionUI`：单个按键重绑定 UI 组件
- `RebindMenuController`：重绑定菜单控制器
