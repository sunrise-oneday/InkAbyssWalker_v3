# 状态机系统

## 泛型状态机框架

### StateMachine\<T\> (`Assets/Scripts/Expolre/State/StateMachine.cs`)
泛型状态机，核心功能：
- `Register(TState state)` - 注册状态
- `Switch<S>()` - 切换到指定状态类型
- `GetState<S>()` - 获取特定状态实例
- `SwitchToPrevious()` - 回退到上一个状态
- `IDeathState` 接口标记的死亡状态切入后永久锁定，拒绝所有后续切换

### BaseState\<T\> (`Assets/Scripts/Expolre/State/BaseState.cs`)
状态抽象基类，生命周期方法：
- `Init(context)` - 初始化（注入所有者引用）
- `Enter()` - 进入状态
- `Update()` / `FixedUpdate()` - 逐帧更新
- `Exit()` - 退出状态
- `stateTimer` - 状态计时器

### IDeathState
死亡标记接口，切入后状态机永久锁定。

## 玩家探索状态 (`Assets/Scripts/Expolre/State/Player/Explore/`)

状态层次结构（继承树）：
```
PlayerState (基类, 自动播放 AnimHash)
  ├── PlayerGroundedState (地面基类: 跳跃/冲刺/连击输入检测, 落地回冲)
  │     ├── PlayerIdleState (待机: 平台锁死防漂移)
  │     ├── PlayerWalkState (行走: 速度=玩家+平台)
  │     └── PlayerAttackState (3连击/JumpCancel/DashCancel)
  └── PlayerAirborneState (空中基类: 空中冲刺/输入丢弃)
        ├── PlayerJumpState (上升段: 固定跳跃力)
        └── PlayerFallState (下落段: 落地切 Walk/Idle)
```

关键设计：
- PlayerGroundedState：集中处理 Jump/Dash/Attack 输入检测，子类无需重复
- 平台物理锁：Idle/Walk 中同步 MovingPlatform2D 速度，防止漂移
- PlayerAttackState：OverlapCircle 检测敌人，命中触发先制战斗；支持 Jump Cancel 和 Dash Cancel 取消后摇
- PlayerDashState：重力清零、方向锁定、持续写入速度

## 玩家战斗状态 (`Assets/Scripts/Battle/Player/`)

8 个状态，在 `PlayerBattleEntity.Awake()` 中注册到独立状态机：
```
PlayerBattleIdleState → PlayerParryState → PlayerCounterAttackState
                      → PlayerBattleDodgeState
                      → PlayerBattleAimState → PlayerBattleUltimateState
                      → PlayerCastSkillState
                      → PlayerBattleDieState (IDeathState)
```

## 敌人探索状态 (`Assets/Scripts/Expolre/State/Enemy/Expolre/`)

4 个状态，驱动 OverworldEnemy 的巡逻行为：
```
EnemyIdleState → EnemyPatrolState → EnemyChaseState → EnemyAttackState
```

## 敌人战斗状态 (`Assets/Scripts/Battle/Enemy/`)

4 个状态：
```
EnemyBattleIdleState → EnemyBattleState → EnemyBattleStunState → EnemyBattleDieState
```

- EnemyBattleState：动画事件全自动驱动变招，不依赖玩家输入
- EnemyBattleStunState：破防后自动切入眩晕
